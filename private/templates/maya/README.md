# Editorial · Frontend

**Maya Lindqvist** — serif editorial portfolio with scroll progress, custom cursor, and hover project previews.

## Files

- `index.html` — structure
- `styles.css` — paper aesthetic, peek card, typography
- `main.js` — scroll progress, custom cursor, project peek follow

## Run locally

```bash
npx serve .
```

## Customize

- Project peek colors use `data-peek` attributes on rows in `index.html`
- Cursor and peek logic in `main.js`
